## インストール時の検討事項

### ファイルシステムの選定

Ubuntu 24.04 のインストーラでは複数のファイルシステムを選択できる。ローカル LLM サーバー用途では以下の観点で検討する。

| ファイルシステム | 特徴 | LLMサーバー向け評価 |
|---|---|---|
| **ext4** | Linuxの定番。枯れた技術で安定性・互換性が高い | ✅ 推奨（シンプル・安定） |
| **xfs** | 大容量ファイルの読み書きに優れる。メタデータ性能が高い | ✅ 推奨（大型モデルファイルに有利） |
| **btrfs** | スナップショット・透過圧縮（zstd）機能あり | △ 圧縮でモデルサイズ削減の可能性があるが、オーバーヘッドに注意 |

**→ 推奨: `ext4`（安定重視）または `xfs`（大容量ファイル重視）**

> LLM モデルファイルは 1 モデルあたり数 GB〜数十 GB になる（例：Llama 3 70B GGUF ≒ 40 GB）。
> btrfs の透過圧縮は GGUF 等の量子化済みバイナリには効果が薄いため、ext4 か xfs が現実的。

### パーティション構成の検討

搭載ストレージは M.2 NVMe 2 TB × 1（スロット空き 1）。インストール初期段階でパーティション設計を決めておくと後の運用が容易になる。

#### 選択肢 A：シンプル構成（推奨・初期構築向け）

| パーティション | サイズ | 用途 |
|---|---|---|
| EFI System Partition | 512 MB〜1 GB | UEFI ブートローダー |
| swap | 8〜16 GB | スワップ領域（メモリ 64 GB のため最小限） |
| `/`（ルート） | 残り全て（≒1.98 TB） | OS・アプリ・モデルファイルすべて |

**メリット:** 管理がシンプル。容量を柔軟に使える。  
**デメリット:** OS 障害時にモデルデータも影響を受ける可能性がある。

#### 選択肢 B：用途別分割構成

| パーティション | サイズ目安 | 用途 |
|---|---|---|
| EFI System Partition | 512 MB〜1 GB | UEFI ブートローダー |
| `/boot` | 1 GB | カーネル・起動ファイル（任意） |
| swap | 8〜16 GB | スワップ領域 |
| `/` | 100〜200 GB | OS・システムアプリ |
| `/var` | 100〜200 GB | ログ・Docker データ（`/var/lib/docker`） |
| `/opt` or `/data` | 残り（≒1.4 TB〜） | LLM モデルファイル置き場 |

**メリット:** ルートと大容量データを分離。Docker やログの肥大化が OS 領域を圧迫しない。  
**デメリット:** パーティションサイズの見積もりが難しく、後から変更しにくい。

**→ 推奨: 選択肢 A（シンプル構成）で開始し、2 本目の NVMe スロットにデータ専用ディスクを追加する運用が柔軟性・拡張性の面で最適。**

### スワップの検討

| 方式 | 内容 | 推奨 |
|---|---|---|
| スワップパーティション | インストール時に確保。SSD 上で高速 | ✅ 8〜16 GB 程度 |
| スワップファイル | 後から `/swapfile` として作成可能 | ✅ 後から調整しやすい |
| zram | メモリ上の圧縮スワップ。Ubuntu 22.04 以降デフォルト有効 | ✅ 補助として併用可 |

> メモリが 64 GB あるため、スワップは OOM（メモリ不足）の安全網として 8〜16 GB あれば十分。
> LLM 推論中にスワップが発生すると著しく性能が落ちるため、スワップへの依存は避ける設計にする。

---

### LLM サーバー用途の固有考慮点

| 項目 | 内容 |
|---|---|
| モデルファイル置き場 | Ollama: `~/.ollama/models`（変更可）、llama.cpp: 任意パス |
| モデルサイズの目安 | 7B GGUF Q4: 約 4 GB、70B GGUF Q4: 約 40 GB |
| Docker 利用時 | `/var/lib/docker` が数十 GB に肥大化することがある。専用領域かシンボリックリンクで対処 |
| tmpfs / キャッシュ | `/tmp` は OS デフォルト（tmpfs）で通常問題なし |
| 2 本目 NVMe スロット活用 | モデルファイル専用ディスクとして追加することで OS 側に影響を与えずに増設可能 |

## 起動用USBメモリ作成（Windows 11）

### 用意するもの

- USBメモリ（8GB以上、推奨16GB以上）
- Ubuntu 24.04 LTS のISOファイル
- Rufus

### 手順

1. Ubuntu公式サイトからISOファイルをダウンロードする
2. Rufusを起動し、対象USBメモリとISOを選択する
3. パーティション構成を `GPT`、ターゲットシステムを `UEFI` に設定する
4. 書き込みを開始する（USB内データは消去される）
5. インストール対象PCでUSBブートしてUbuntuをインストールする
